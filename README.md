# Сервис учета городских событий (City Events Service)

## Назначение
Веб-приложение для учета, хранения и просмотра городских событий.
Позволяет организаторам публиковать мероприятия, а жителям и гостям
города — находить интересные события по категориям, местам и датам.
Приложение решает задачу централизованного сбора информации о том,
что, где и когда происходит в городе.

## Целевая аудитория
- Жители города, ищущие мероприятия для досуга
- Туристы и гости города
- Организаторы событий (концертов, выставок, спортивных мероприятий)
- Администраторы городских площадок и культурных центров

## Предметная область
Учет городских событий: каждое событие имеет название, описание,
дату и время проведения, место проведения и категорию.
События привязываются к конкретным местам города и группируются
по категориям (концерты, выставки, спорт, театр, образование и т.д.).
Пользователи могут просматривать события, фильтровать их по категории,
дате и месту проведения.

## Основные сущности
- **Событие (Event)** — название, описание, дата и время, место, категория
- **Место (Place)** — название площадки, адрес, координаты
- **Категория (Category)** — название и описание категории события

## Основные функции
- Просмотр списка городских событий
- Просмотр подробной информации о событии
- Фильтрация событий по категории, дате и месту проведения
- Поиск событий по названию
- (в перспективе) регистрация пользователей и создание событий
- (в перспективе) административная панель для модерации событий

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
