# City Events Service (Сервис учета городских событий)

## Назначение
Веб-приложение для учета и просмотра городских событий: концертов,
выставок, спортивных мероприятий и т.д.

## Целевая аудитория
- Жители и гости города, ищущие события
- Организаторы мероприятий
- Администраторы городских площадок

## Предметная область
Учет событий, привязанных к местам проведения и категориям,
с указанием даты и времени.

## Основные сущности
- **Event (Событие)** — название, описание, дата, место, категория
- **Place (Место)** — название, адрес
- **Category (Категория)** — название, описание

## Основные функции
- Просмотр списка событий
- Фильтрация по категории и дате
- Просмотр деталей события
- (в будущем) регистрация пользователей, создание событий, API

## План развития проекта
1. ПР1 — CLI-скрипт добавления/просмотра события
2. ПР2 — структуры данных и классы
3. Django-приложение с моделями и админкой
4. Аутентификация пользователей
5. REST API (DRF)
6. Деплой
