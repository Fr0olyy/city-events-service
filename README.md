# Сервис учета городских событий (City Events Service)

## Назначение
Консольное приложение для учета, хранения и просмотра городских
событий. Позволяет вести справочник мест и категорий, добавлять
события с привязкой к месту и категории, искать события по
названию и дате, регистрировать участников. Данные сохраняются
в JSON-файлах и восстанавливаются при следующем запуске.

## Целевая аудитория
- Жители города, ищущие мероприятия для досуга
- Туристы и гости города
- Организаторы событий (концертов, выставок, спортивных
  мероприятий)
- Администраторы городских площадок и культурных центров

## Предметная область
Учет городских событий: каждое событие имеет название, дату
проведения, место проведения и категорию. События привязываются
к конкретным местам города и группируются по категориям
(концерты, выставки, спорт, театр, образование и т. д.).
Пользователи могут просматривать события, фильтровать их
по категории и дате, регистрироваться на события.

## Основные сущности
- **Событие (Event)** — id, название, id места, id категории,
  дата проведения
- **Место (Place)** — id, название площадки, адрес
- **Категория (Category)** — id, название, описание
- **Регистрация (Registration)** — id, id события, имя участника

## Основные функции
- просмотр списка событий, отсортированных по дате;
- поиск событий по подстроке в названии;
- фильтрация событий по категории и по дате;
- просмотр и поиск мест по названию или адресу;
- просмотр категорий;
- добавление мест, категорий и событий;
- регистрация участника на событие и отмена регистрации;
- определение статуса события относительно текущей даты;
- сохранение и загрузка данных в JSON-файлах.
